# Ejercicio 02: Monitoreo de sobrecalentamiento de un motor

## Enunciado

Desarrolla un algoritmo que lea la temperatura actual de un motor mediante un sensor y determine si el motor debe apagarse por sobrecalentamiento.

## Investigación y Supuesto Técnico
Un motor de auto a gasolina funciona regularmente a una temperatura de entre 90 °C y 100 °C

## Escrito:

1. Inicio;
2. Mensaje de salida 'Favor de ingresar la temperatura actual del motor';
3. Almacena el dato en la variable TEMPERATURA;
4. Establecer el límite máximo de temperatura permitido;
5. Comparar si la TEMPERATURA es mayor o igual al límite establecido;
6. Si la temperatura supera el límite, mostrar el mensaje 'ADVERTENCIA: SOBRECALENTAMIENTO, EL MOTOR DEBE APAGARSE';
7. De lo contrario, mostrar el mensaje 'TEMPERATURA NORMAL, EL MOTOR PUEDE CONTINUAR FUNCIONANDO';
8. FIN;
